# Rebuilt eSpeak NG phonemizer for the Kokoro worker

This is the independently rebuilt eSpeak component used by the local Kokoro worker. Its eSpeak source is the included complete upstream archive at commit `0dfd1d77dd7f96ef1ea6856c9fa5cfac01599582`, SHA-256 `e6b84b52a87b3ad72885331bd942b2adecd70c384fa4ecfbe10aae7d9afd5e21`. Source: https://github.com/espeak-ng/espeak-ng/tree/0dfd1d77dd7f96ef1ea6856c9fa5cfac01599582 . The existing `phonemizer` npm package's opaque prebuilt engine is NOT used to build this replacement.

Tested on Linux with native GCC `13.3.0` (Ubuntu `13.3.0-6ubuntu2~24.04.1`), CMake `3.28.3`, and Emscripten SDK `3.1.64`: emsdk repository commit `0b3bcbc3b005cbb811d48e497eabcc6846d43001`, Emscripten SDK release `fd61bacaf40131f74987e649a135f1dd559aff60`. Install/activate that private SDK, put CMake and a native C/C++ toolchain on PATH, set EMSDK to the SDK path, and run `./build.sh` in a directory with write access. The script checks the source archive and Emscripten version, then applies the two included patches, builds eSpeak's dictionary/data compiler natively, creates the data from source, builds the static library for WebAssembly, and embeds just the resulting English data into the JS/WASM module. It does not fetch dependencies. Build output is under `build/output/`; it does not rebuild or modify the main game worker.

A clean rebuild on the same host produced a byte-for-byte identical `espeak.mjs` (SHA-256 `772a0b00d54689b090536e4752b46f2a8ea4eb31899f623a1345d7ec7f9d0860`). Bit-identical output on other toolchains or platforms is not established. Both patches are included: skip optional Sonic's implicit network fetch; include the C standard wchar header before an eSpeak compatibility shim to avoid Emscripten header conflicts. The first build's native English data and a rebuild with both patches produced matching data hashes.

`adapter.c` and `index.js` provide the minimal phonemization API used by Kokoro. The embedded files in `/usr/share` and temporary output path are Emscripten's virtual filesystem, not the user's host disk. Only `en` and `en-us` are provided. Preserve the bundled eSpeak copyright/license notices and the source offer/distribution obligations for the actual distribution. eSpeak NG is GPL-3.0-or-later; upstream also supplies the included Apache, BSD and UCD notices. Other game/Kokoro dependencies carry their own licenses and are outside the scope of this component bundle.

The replacement produced exactly matching IPA against the old engine for all 1,183 scripted voice lines catalogued at the time, using the appropriate US or British English voice family. This corpus test does not cover arbitrary future generated dialogue. Offline browser audio comparisons are recorded in `../BUILD.md`.

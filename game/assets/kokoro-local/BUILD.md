# Rebuilding the local speech worker

The locked source and build scripts are in `source/`. They build the eSpeak NG phonemizer from the complete pinned upstream source archive, not from the earlier phonemizer.js package's opaque precompiled engine. See `source/README.md` for the precise source revision, archive hash, patches, toolchain and license notices.

With Node 22, npm, the pinned Emscripten 3.1.64 SDK activated, CMake, a native C/C++ compiler and `patch` available, run `source/build.sh` then `source/build-worker.sh`. The first script produces `source/build/output/espeak.mjs`; the second installs the exact npm dependency tree in `source/package-lock.json`, patches Kokoro's voice URL to the local voice embeddings, replaces the phonemizer with the newly built source component, and bundles `worker-build.js`. npm needs access to its package cache or registry during this build; playback does not.

On the tested Linux toolchain, a fresh eSpeak build produced exactly the same module as the independently built candidate (SHA-256 `772a0b00d54689b090536e4752b46f2a8ea4eb31899f623a1345d7ec7f9d0860`). The bundled `worker.js` built with the locked npm dependencies has SHA-256 `a924fd46cf4cea05bb1e008eb3991862a9b07eb2ffa067f9d30f071cab9c4626`. Bit-for-bit reproducibility on other toolchains is not established. Existing ONNX Runtime Web binaries in `runtime/` are separate upstream binaries and were not rebuilt by these scripts.

The new eSpeak engine's IPA output matched the previous engine on all 1,183 existing scripted voice entries. In an offline Chromium comparison, the previous and rebuilt workers produced identical non-silent audio samples for seven voice embeddings across two sample phrases each, and again across two scripted story lines selected for each voice (14 pairs), with external requests blocked. A real game UI test also synthesized and played the opening narration using this worker while prerecorded clips were unavailable. This is not proof of identical handling of every possible future AI-generated line, or compatibility on every device.

# Local Kokoro speech

This directory contains Kokoro-82M's q8 ONNX model, seven Kokoro voice embeddings and a browser worker bundling Kokoro.js, Transformers.js and an eSpeak NG phonemizer with ONNX Runtime Web. It synthesizes on-device; it does not send text to a server or fetch a CDN. Model: https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX/tree/1939ad2a8e416c0acfeecc08a694d14ef25f2231 (Apache-2.0). Kokoro.js 1.2.1 https://github.com/hexgrad/kokoro (Apache-2.0); Transformers.js 3.8.1 https://github.com/huggingface/transformers.js (Apache-2.0); ONNX Runtime Web 1.22.0-dev.20250409-89f8206ba4 https://github.com/microsoft/onnxruntime (MIT). The phonemizer is built from eSpeak NG at https://github.com/espeak-ng/espeak-ng/tree/0dfd1d77dd7f96ef1ea6856c9fa5cfac01599582 (GPL-3.0-or-later). Consult the included license texts and corresponding source before distributing.

Worker source, exact dependency lock, complete eSpeak source archive, patches and build instructions are provided in `worker-source.js`, `source/` and `BUILD.md`. Kokoro loads voice embedding files from this directory rather than the default remote URL. Local inference requires WebAssembly and module workers. Compatibility and speed depend on the browser and hardware.

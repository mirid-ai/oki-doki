# Oki Doki: The Last Ticket

A cosy arcade prize hunt becomes a psychological mystery in this original, open-source visual novel. Spend time with Niko, Mira, Ash and Mallow, choose what to say, and see where an unusually reassuring welcome service leads.

Oki Doki began as a response to its creator's recollection of Aviva Sofia ASMR wishing for another *Doki Doki Literature Club*. It is an unofficial spiritual successor with its own characters, setting and art. It is not affiliated with Team Salvato, and Aviva Sofia ASMR is not involved and has not endorsed it.

## Desktop preview

Windows and Linux downloads are available in the [preview release](https://github.com/mirid-ai/oki-doki/releases/tag/v0.1.0-preview). Extract the ZIP and run **Oki Doki.exe** on Windows or **Oki Doki** on Linux; each download includes instructions, prerecorded voices, local speech synthesis, music, effects, an optional local dialogue model and optional speech recognition.

The Linux build was tested on Ubuntu 24.04 x64. An earlier Windows build was exercised under Wine; a full route in the current build remains unverified, and native Windows has not been tested. The Windows preview is unsigned. See [release notes](game/README.md#desktop-downloads) and the START-HERE file in each download for requirements and details.

The main story and outcomes are written. In selected conversations, optional AI can respond to a player's own words. Open **AI settings**, choose **Set up included AI and microphone**, and save for the session to use the bundled local model and transcription. Model responses can be inconsistent. See [how the game and AI work](game/README.md) and the [design notes](game/DESIGN.md).

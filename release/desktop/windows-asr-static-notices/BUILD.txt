The upstream project automatically applies its own in-tree ggml patches at
configuration. The additional mingw-header-compat.patch guards a Windows
power-throttling optimization when older MinGW headers lack its definitions.

Build used Ubuntu noble's g++-mingw-w64-x86-64-posix and
 gcc-mingw-w64-x86-64-posix 13.2.0-6ubuntu1+26.1,
mingw-w64-x86-64-dev 11.0.1-3build1, cmake 3.28.3-1build7, and GNU make.
Configuration from source, after initializing the ggml submodule and applying
the compatibility patch on top of the project's own ggml patches:

bash scripts/apply_ggml_patches.sh
(cd third_party/ggml && git apply /path/to/mingw-header-compat.patch)
cmake -S parakeet.cpp -B build -DCMAKE_SYSTEM_NAME=Windows \
  -DCMAKE_C_COMPILER=x86_64-w64-mingw32-gcc-posix \
  -DCMAKE_CXX_COMPILER=x86_64-w64-mingw32-g++-posix \
  -DCMAKE_BUILD_TYPE=Release -DPARAKEET_WITH_CED=OFF \
  -DPARAKEET_WITH_VOICEDETECT=OFF -DPARAKEET_BUILD_SERVER=OFF \
  -DPARAKEET_BUILD_TESTS=OFF -DGGML_NATIVE=OFF -DGGML_OPENMP=OFF \
  -DBUILD_SHARED_LIBS=OFF \
  -DCMAKE_EXE_LINKER_FLAGS='-static -static-libgcc -static-libstdc++'
cmake --build build --target parakeet-cli -j 8
